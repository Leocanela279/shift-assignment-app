# Cuadra

Herramienta web gratuita y sin registro para crear cuadrantes de trabajo y descargarlos en PDF.

## MVP

- Cuadrantes por siglas de turno o por horarios libres.
- Nombre y logo de empresa personalizables.
- Turnos y franjas horarias editables.
- Gestión del equipo y edición rápida por arrastre.
- Guardado automático en el navegador.
- Exportación directa a PDF apaisado.

Los datos no salen del dispositivo. El MVP no necesita backend, cuenta de usuario ni base de datos.

## Desarrollo

Requiere Node.js 22.13 o posterior.

```bash
npm install
npm run dev
```

Para comprobar la versión de producción:

```bash
npm run build
```
